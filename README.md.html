Vision Encoder (ViT)

The image is split into fixed-size patches (e.g. 16×16 pixels), linearly embedded, and fed into a Transformer encoder. The model learns spatial relationships between patches using self-attention — enabling it to capture global context far beyond what CNNs handle locally.

Language Decoder

Image feature vectors from the ViT encoder are passed to an autoregressive decoder initialized with a BERT tokenizer and enhanced with GloVe word embeddings. The decoder generates one token at a time using cross-attention over visual features to produce fluent, descriptive captions.

Capabilities
Key features

Automatic captioning

Upload any image and receive a human-readable description generated entirely by the AI pipeline — no templates or rules.

ViT patch attention

Divides images into patches and applies multi-head self-attention, allowing the model to reason about the whole scene contextually.

Flutter frontend

A polished cross-platform mobile UI built with Flutter, designed in Figma. Supports live image picking and real-time caption display.

GCP cloud deployment

Flask API hosted on Google Cloud Platform for scalable, reliable inference. Supports REST-based image uploads and JSON responses.

REST API integration

Clean endpoint design: POST an image, receive a caption. Easily extendable for batch processing or third-party integrations.

Large-scale training

Trained on Flickr30k and MS COCO — two of the most widely used benchmark datasets for image captioning research.

Datasets

Flickr30k

31,783 images 158,915 captions 5 captions / image

A widely used benchmark for sentence-based image description. Covers everyday scenes including people, animals, activities, and objects with diverse natural language annotations written by crowd workers.

MS COCO

330k+ images 1.5M+ captions 80 object categories

Microsoft Common Objects in Context — the standard large-scale dataset for image captioning, detection, and segmentation. Provides rich visual diversity across complex real-world scenes and activities.

Getting started
Installation
1 · Clone the repository
git clone https://github.com/your-username/ImageSpeak.git
cd ImageSpeak
2 · Install Python dependencies
pip install -r requirements.txt
3 · Run the Flask server
python app.py
# Server starts at http://localhost:5000
4 · Run the Flutter application
flutter pub get
flutter run
5 · Sample API usage
# POST an image to get a caption
curl -X POST https://<your-api>/caption \
-F "image=@photo.jpg"

# Response
{ "caption": "A dog running on a grassy field near a lake." }
